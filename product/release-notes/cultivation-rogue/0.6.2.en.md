Cultivation: Dispatch 0.6.2

This is the first build of this pack whose data files use the ids the engine
actually reads.

The 0.6.0 and 0.6.1 archives do not install. The engine refused them with V-14
on eleven resource ids and V-16 on eight action ids, because those ids carried
a dot or a hyphen (`belief.sword`, `send-apan-herb`). Every one of them is a
lowercase id now, and the archive carries the same story as before — five
realms, two acts, nine generations inside one run, waves that read the seat.

What changed since 0.6.1:

- Every action id and resource id matches the engine's grammar.
- The English table still carries a line for every action, rank, failure and
  labelled resource value: 98 of 98.

Install it by hand — the engine cannot install from a link, because the browser
blocks the cross-origin fetch:

1. Download `cultivation-rogue.zip` from the assets below.
2. Open the engine, open the packs screen, and choose the option that installs a
   pack from a zip file. Labels follow your interface language.
3. Pick the file you downloaded. The pack appears as Cultivation: Dispatch (the
   Chinese name reads 修仙·派遣).

Known limits, unchanged by this release:

- A disabled action explains itself with the resource key rather than a
  sentence, because the engine builds that line without the locale table.
- `meta.minutes` still says 8; a full run of nine generations takes about
  twenty to twenty-five minutes.
