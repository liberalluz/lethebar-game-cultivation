### Added

- A dispatch loop: three named disciples (Apan, Aying and Asu) can be sent to
  the herb valley or into the ruins, and each trip moves that disciple's
  injury, trust or greed — not only the stone pile.
- `data/phases.json`: twelve days, three ranks, and one way for each disciple
  to be lost.

### Changed

- The four endings of the first act no longer close the run; each one opens the
  gate and hands the player to the twelve days behind it.
- A disciple at injury 2 or more cannot be sent out, and the menu says so
  instead of hiding the button.

### Fixed

- The English table now names every ledger label. It was missing the nineteen
  labels of the first act's five values, and the engine refuses to install a
  pack whose locale table leaves a menu label unnamed — so 0.3.0 was turned
  away at install. 0.4.0 installs.
